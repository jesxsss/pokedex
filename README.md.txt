Tutorial: Creación de Cuenta en Azure for Students
Este documento detalla los pasos seguidos para crear una cuenta en la plataforma Azure for Students, la cual se utilizará para desplegar la aplicación PokeDex.

Paso 1: Acceso al portal de Azure
Ingresar a la página web oficial de Azure for Students y hacer clic en el botón verde de activación que indica “Inicie de forma gratuita”.

Paso 2: Autenticación con correo institucional
En la pantalla de inicio de sesión de Microsoft, ingresar el correo electrónico institucional proporcionado por la universidad. El sistema redirigirá a la página de autenticación de la institución educativa para ingresar la contraseña. Este paso es obligatorio para validar el estatus de estudiante.

Paso 3: Verificación de identidad
Completar los pasos de seguridad adicionales que solicite la cuenta, como la verificación en dos pasos (MFA) a través del teléfono móvil o una aplicación autenticadora.

Paso 4: Creación del perfil y suscripción
Llenar el formulario de registro de Azure con los datos personales básicos (nombre, número de teléfono y país). Leer y aceptar el acuerdo de suscripción y los detalles de la oferta. Al no requerir tarjeta de crédito, la cuenta quedará activada inmediatamente con la suscripción “Azure for Students” lista para usarse en portal.azure.com.
